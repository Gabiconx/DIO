# 📈 Simulador de Investimentos em Excel

Desafio prático desenvolvido durante o Bootcamp Santander - Excel com IA.

## 📌 Sobre o Projeto
Ferramenta desenvolvida no Microsoft Excel para simulação de investimentos, aplicando cálculos financeiros como rendimento mensal e projeção de dividendos.

## 🛠️ Funcionalidades
- **Simulação de Rendimento Mensal:** Aplicação de taxas e fórmulas financeiras para projeção de crescimento de capital.
- **Cálculo de Dividendos:** Estimativa de proventos e dividendos com base nos ativos.
- **Organização:** Layout e formatação técnica para fácil interpretação dos dados.
